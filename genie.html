Genie’s Wish Portal

Bekijk live project → Bekijk trailer ↓

Over dit project

Voor mijn individuele project heb ik Genie’s Wish Portal gemaakt. Dit is een interactieve AR/3D-game die ik heb gebouwd met HTML, CSS en JavaScript. Het idee achter de game is dat de gebruiker een magische wereld binnenstapt, een lamp ontdekt en daarna een wens kan kiezen.

De gebruiker kan kiezen uit drie wenswerelden: rijkdom, liefde en avontuur. Elke wereld heeft een eigen sfeer en visuele stijl. Hierdoor voelt de keuze niet alleen als een knop op een website, maar als een onderdeel van een verhalende ervaring.

Het concept

Het concept draait om verwondering, ontdekking en keuze. In plaats van een normale website wilde ik een ervaring maken waarin de gebruiker echt door een digitale wereld kan bewegen. De lamp staat centraal in de ervaring. Wanneer de gebruiker hiermee interacteert, verschijnt de Genie en kan er een wens worden gekozen.

Ik wilde dat de website meer voelde als een kleine magische belevenis dan als een standaard projectpagina. Daarom heb ik gewerkt met 3D-elementen, een portal, een lamp, een Genie en verschillende werelden.

Technische uitwerking

Ik heb de game technisch opgebouwd met HTML, CSS en JavaScript. Dit vond ik best lastig, omdat ik nog niet alles wist over het werken met interactieve 3D-elementen en een AR-achtige webomgeving. Daarom heb ik veel online opgezocht, voorbeelden bekeken en stap voor stap getest wat wel en niet werkte.

Tijdens het bouwen liep ik tegen verschillende problemen aan, zoals objecten die niet goed stonden, elementen die in verkeerde werelden zichtbaar bleven en interacties die niet meteen logisch werkten. Door telkens te testen en aan te passen heb ik de flow steeds duidelijker gemaakt.

  • De gebruiker start op een introductiescherm
  • Daarna gaat de gebruiker naar de 3D/AR-wereld
  • De lamp vormt het centrale interactiepunt
  • Na interactie verschijnt de Genie
  • De gebruiker kiest uit rijkdom, liefde of avontuur
  • Daarna wordt de gebruiker naar de gekozen wenswereld gebracht

Ontwerp en sfeer

Voor de uitstraling heb ik gekozen voor een magische sfeer met paars, licht, portalen en fantasie-elementen. De drie wenswerelden zijn bewust verschillend gemaakt, zodat de gebruiker direct merkt dat elke wens een eigen betekenis en beleving heeft.

Rijkdom is gekoppeld aan luxe en gouden elementen, liefde aan zachte en romantische objecten en avontuur aan een ontdekkende wereld met een schip en jungle-achtige sfeer. Hierdoor worden de werelden niet alleen visueel anders, maar ook inhoudelijk herkenbaar.

Documentatie en feedback

Naast het bouwen van de game heb ik het project ook gedocumenteerd. In mijn documentatie heb ik beschreven hoe mijn concept is ontstaan, welke ontwerpkeuzes ik heb gemaakt en hoe ik feedback heb verwerkt. Uit feedback kwam onder andere naar voren dat de interactie met de lamp duidelijker moest worden en dat de wenswerelden sterker van elkaar moesten verschillen.

Deze feedback heb ik meegenomen in mijn eindproduct. Ik heb de lamp centraler gemaakt, de gebruiker meer richting gegeven en de verschillende werelden duidelijker uitgewerkt. Daardoor werd de ervaring beter te begrijpen en sterker als geheel.

Wat ik heb geleerd

Tijdens dit project heb ik geleerd dat een goed idee pas echt werkt wanneer de gebruiker ook begrijpt wat hij moet doen. In het begin was mijn concept vooral visueel sterk, maar tijdens het bouwen merkte ik dat de interactie en flow minstens zo belangrijk zijn.

Ook heb ik geleerd om zelf problemen op te lossen door online informatie op te zoeken, code te testen en fouten stap voor stap te verbeteren. Dit project was technisch uitdagend, maar juist daardoor heb ik veel geleerd over HTML, CSS, JavaScript en het maken van een interactieve webbeleving.

Resultaat

Het eindresultaat is een interactieve AR/3D-webgame waarin de gebruiker een magische wereld kan verkennen, een lamp kan activeren en daarna een wenswereld kan kiezen. Het project laat zien hoe ik een creatief concept heb uitgewerkt naar een werkende technische ervaring.

Voor mijn portfolio vind ik dit een belangrijk project, omdat het mijn ontwikkeling laat zien op het gebied van conceptontwikkeling, visueel ontwerp, interactie, documentatie en front-end development.
